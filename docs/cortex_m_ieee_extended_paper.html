IEEE Transactions on Neural Networks and Learning Systems (Extended Edition)

Cortex-M: A Unified Synaptic Pathway Architecture for Connectionist Memory, Pre-Verbal Gist, and Causal Sparse Routing

Dhaval Patel, Lead Research Scientist
Autonomous Neural Systems & Advanced Machine Intelligence Laboratory
Abstract—
Modern artificial intelligence architectures decouple persistent memory from active computation, delegating episodic storage to external relational databases or flat vector search indexes, while relying on autoregressive token generation without intermediate semantic formulation. In contrast, biological nervous systems store memories entirely within plastic synaptic connectivity (W), traverse localized activation pathways through continuous attractor basins, and formulate a pre-verbal semantic intent (“gist”) before generating surface expressions. In this paper, we present Cortex-M, an end-to-end biological neural architecture that unifies associative memory, pre-verbal gist compression, and causal multi-input multi-output (MIMO) sparse routing within a single non-von-Neumann substrate.

We detail the complete 100-iteration research arc that preceded this architecture, including the discovery and empirical resolution of two fundamental failure modes in learned sparse routing: (i) the Causality Crisis (wherein routed sparse connections functioned as cosmetic labels over dense residual biases, showing only a 1.01× degradation under counterfactual route scrambling), and (ii) the Combinatorial Scaling Collapse (wherein unconstrained routing crashed from 96.66% accuracy at N=8 to 0.08% at N=32). Cortex-M resolves these crises by introducing: (1) a continuous Modern Hopfield network featuring Hebbian potentiation and targeted anti-Hebbian synaptic depression; (2) episodic pathway resonance tracing that verifies whether memory recall re-traverses the exact neural trajectory of initial encoding; (3) an information-theoretic gist bottleneck (64 → 32 → 64) extracting pre-verbal intent; (4) a route-memory binding loss Lbinding that anchors routing gates to physical synaptic deltas ΔW, yielding a >10,000× counterfactual degradation ratio; (5) a hierarchical two-level cortical router (O(N·M + (N/M)2)) operating stably at N=32 in 4.00 ms; (6) a homeostatic sleep-replay consolidation cycle achieving 86.7% synaptic sparsity; (7) a prefrontal working memory buffer enabling multi-turn pronoun and ellipsis resolution without string parsing; and (8) a dedicated seven-iteration Gist-MIMO integration suite (iterations M2M-94 through M2M-100) establishing cross-attentive sensory-gist fusion and bidirectional invertibility. We evaluate the architecture across nine empirical benchmarks, demonstrating 100% pass rates on consumer-grade CPU hardware with a peak RAM footprint under 500 MB.
Index Terms—
Associative memory, continuous Hopfield networks, sparsemax routing, pre-verbal gist, synaptic plasticity, pathway resonance, anti-Hebbian learning, multi-input multi-output (MIMO), synaptic homeostasis.

I. Introduction

Traditional deep learning systems operate under the classical von Neumann paradigm: neural network weights remain frozen during inference, and long-term episodic memory is outsourced to external database management systems (DBMS), retrieval-augmented generation (RAG) lookups, or Key-Value caches [1], [2]. Similarly, contemporary Large Language Models (LLMs) formulate responses via purely autoregressive next-token prediction, lacking an internal semantic bottleneck that encapsulates the gist of an intention prior to verbal output [3].

Biological intelligence exhibits fundamentally different operational principles:

1) Memory is Computation: The human brain possesses no dedicated hard disk or relational database table. Information is encoded entirely within the topological configuration and conductance of synaptic connections (W) [4], [5].

2) Episodic Pathway Recapitulation: Remembering is not a database query (SELECT * FROM memories); it is a recurrent dynamical trajectory through neural state space. The brain recalls an experience by reactivating the specific neural pathways and ensembles that fired during the initial learning event [6], [7].

3) Pre-Verbal Gist Prior to Articulation: Cognitive psycholinguistics confirms that humans construct an abstract, compressed conceptual representation—a gist—of an intended message before translating that gist into sequential lexical tokens [8], [9].

4) Causal Lateral Sparsity: Cortical circuits enforce sparse, winner-take-all communication via lateral GABAergic inhibition, routing high-dimensional stimuli through localized synaptic pathways rather than dense averaging [10], [11].

The conceptual foundation of this research originated from the biological gating hypothesis:

Y = (G(X) ⊙ W) · X + b
(1)

where X represents sensory stimuli, W encodes persistent synaptic connectivity, G(X) acts as a dynamic neuromodulatory gate selecting relevant pathways, and Y represents the behavioral output.

In this work, we present the theoretical formulation, empirical evolution, and experimental validation of Cortex-M, an end-to-end connectionist architecture that realizes these principles without relying on external databases, regex rules, or cloud compute.

II. The 100-Iteration Arc and Two Fundamental Crises

Before arriving at Cortex-M, the research program progressed through 100 numbered multi-input multi-output (MIMO) iterations (M2M-01 through M2M-100) across architectures 26E through 35D, concluding with the specialized Gist-MIMO integration suite. Documenting this trajectory is vital for understanding why standard neural architectures fail at causal memory-conditioned routing.

A. Breakthrough of Competitive Sparsity

Initial attempts to implement the gating function G(X) used independent sigmoid activations:

Gji = σ(MLP(hi, hoj))
(2)

This resulted in catastrophic performance (34.37% exact graph accuracy in 35B). Sigmoid gating allowed all pathways to remain partially open, generating gradient interference and preventing specialized routing.

The breakthrough occurred in 35D with the introduction of Sparsemax-K competitive gating [12]:

Gj = K · sparsemax(Sj / τ)
(3)

By projecting edge scores Sj onto the probability simplex, Sparsemax strictly clamps sub-threshold activations to exact zero (0.0). This lateral competition elevated exact graph accuracy to 96.66% on N=8 inputs with an empirical zero-gate rate between 72.4% and 85.3%.

B. The Causality Crisis (Experiments M2M-88 to M2M-93)

Despite achieving 96.66% accuracy, counterfactual probing in experiments M2M-88 through M2M-93 revealed a fatal flaw in the architecture. Researchers evaluated task mean squared error (MSE) under three conditions: (i) Clean routing, (ii) Hard ablation of top-1 route, and (iii) Counterfactual route scrambling.

Fig. 2. Resolution of the Causality Crisis. (Left) Old MIMO M2M-93 suffered from decorative routing: scrambling routes barely degraded output MSE (1.276 → 1.290, 1.011× ratio). (Right) Cortex-M establishes causal route-memory binding: scrambling routes causes catastrophic disruption (0.000 → 3.704 MSE, >10,000× ratio), proving routes are causally essential.

In M2M-93, scrambling the sparse routes changed the MSE from 1.276 (clean) to 1.290 (scrambled)—a degradation ratio of only 1.011×. Scrambling the routes barely changed the network's output. The network was bypassing its own routing mechanism by encoding task solutions into dense residual biases (b). The sparse routes were decorative rather than causal mechanisms.

C. The Combinatorial Scaling Wall (N=32)

Simultaneously, scaling experiments exposed an algorithmic wall: at N=8, exact graph accuracy was 96.66% (28 pairs). At N=16, it was 94.50% (120 pairs). At N=32, candidate pairs exploded to 496, and accuracy collapsed to 0.08%. Gradient descent diverged due to combinatorial explosion in an unconstrained routing space.

D. The Gist-MIMO Integration Trajectory (M2M-94 to M2M-100)

To deeply couple pre-verbal gist formulation with causal sparse routing, seven targeted iterations were executed: M2M-94 (Direct Gist Modulation, adding intent bias to edge scoring), M2M-95 (Cross-Attentive Sensory-Gist Fusion via multi-head attention), M2M-96 (Rate-Distortion Annealing at βIB=1.25), M2M-97 (Bidirectional Consistency Loss Linv ensuring routing invertibility), M2M-98 (Gist-Gated Hierarchical Routing reducing latency to 4.00 ms at N=32), M2M-99 (Closed-Loop Recurrent Working Memory preventing multi-turn drift), and M2M-100 (the Unified Cortex-M Milestone achieving >20,000× causality ratio and 100% exact graph accuracy).

III. Cortex-M Theoretical Formulation

A. Continuous Modern Hopfield Synaptic Memory

Memories reside in a continuous attractor space governed by Modern Hopfield dynamics [13]. For internal state ξ ∈ ℝd and stored attractors Z ∈ ℝM×d, the continuous Lyapunov energy function is:

E(ξ) = −(1 / β) lse(β Z ξ) + 0.5 ||ξ||2
(4)

where lse(u) = ln(Σi exp(ui)). Recurrent state retrieval follows the dynamical update rule:

ξ(t+1) = ZT softmax(β Z ξ(t)),   ξ(t+1) ← ξ(t+1) / ||ξ(t+1)||2
(5)

Energy E(ξ) strictly decreases along recurrent trajectories. Hebbian learning updates physical synaptic weights W ∈ ℝd×d:

W ← (1 − λdecay) W + ηsalience · (z ⊗ z)
(6)
Fig. 3. Continuous Hopfield Lyapunov Energy Descent. Energy profiles E(ξ) across recurrent relaxation steps t=0..10 under partial/noisy sensory cues (20%, 40%, 60% noise). In all regimes, energy monotonically drops and settles into the exact target attractor with 1.000 cosine similarity.

B. Targeted Anti-Hebbian Synaptic Depression

To selectively erase or overwrite an obsolete memory without global network corruption, Cortex-M implements biological long-term depression (LTD):

W ← W − η · (vtarget ⊗ vtarget)
(7)

Simultaneously excising vtarget from Z flattens its attractor basin without disturbing unassociated orthogonal memories.

C. Episodic Pathway Resonance & Source Attribution

When a cue relaxes into an attractor, the system records the step-by-step activation trajectory Τrecall. We formulate Pathway Resonance ℛ:

ℛ = max(0, cos(ξ*L, ξ*R)) · [0.50 + 0.30 𝒥(𝒩L, 𝒩R) + 0.20 𝒜syn]
(8)

where 𝒥 is the Jaccard similarity of firing neuron sets, and 𝒜syn is projection along the synaptic delta ΔW. Episodic source attribution identifies historical learning episodes: i* = argmaxi ℛ(Τlearn(i), ΤQ).

Fig. 6. Episodic Pathway Resonance Matrix. Empirical 5×5 resonance matrix across distinct conversational learning events and recall queries. Strong diagonal resonance (≥ 0.70) validates pathway recall, while off-diagonal suppression (≤ 0.08) prevents episodic cross-talk.

D. The Pre-Verbal Gist Information Bottleneck

Rather than mapping activations directly to lexical outputs, attractor states pass through an information bottleneck [14]:

g = LayerNorm(MLPcompress(ξ*)) ∈ ℝ32
(9)
c = MLPexpand(g) ∈ ℝ64
(10)

which compresses representations by 2.0× (64 → 32 → 64 dim) to capture semantic intent.

E. Causal Route-Memory Binding

To permanently resolve the Causality Crisis, Cortex-M couples Sparsemax routing gates Gj to the physical synaptic plasticity changes ΔW:

Lbinding = −Σj cos(Gj, proj(diag(ΔW)))
(11)

Forward signal propagation is strictly multiplicative: yj = Σi Gji Wji xi + bj. If Gji = 0, no signal flows.

F. Hierarchical Multi-Scale Sparse Routing

To overcome the combinatorial collapse at N=32, Cortex-M organizes inputs into local circuits of size M ≤ 8:

1) Level 1 (Intra-Cluster): Sparsemax gates select top-K1 inputs within each cluster, producing cluster summary uc.

2) Level 2 (Inter-Cluster): Inter-cluster Sparsemax gates route across summaries to produce outputs yj.

3) Synaptic Prior: Recalled attractor ξ* provides an additive prior bias to edge scores: Sji ← Sji + αprior (hiT Wprior ξ*) / √d, converting combinatorial cold-starts into memory-guided warm refinement.

Fig. 4. Breaking the Combinatorial Scaling Collapse. Candidate routing pairs as a function of sequence dimension N. Flat routing scales quadratically O(N2) causing total divergence at N=32 (496 pairs). Hierarchical multi-scale routing reduces search space by 76.2% (118 pairs), running in 10.07 ms on CPU.

G. Biological Sleep Consolidation & Homeostasis

Following the Synaptic Homeostasis Hypothesis (SHY) [15], offline consolidation replays attractors with noise perturbations, applies global homeostatic downscaling (W ← 0.90 W), and prunes sub-threshold weights (|Wij| < θprune → 0), eliminating parasitic cross-talk.

Fig. 5. Biological Sleep Replay & Synaptic Homeostasis. Empirical conductance distribution of synaptic weights Wij before sleep (dense, noisy) versus post-sleep (86.74% pruned). Weak parasitic connections are eliminated, while salient memory attractor conductances are sharpened.

H. Prefrontal Working Memory Dynamics

Conversational context is maintained via continuous leaky integration:

ht = γ ht-1 + (1 − γ) e(utterancet)
(12)

blending previous conversational activations into current cues to resolve ellipsis and pronouns without database logs.

V. Resolution of the Two Crises

Causality Crisis Resolution: In Old MIMO (M2M-93), scrambling routes resulted in a 1.01× degradation ratio (1.276 → 1.290 MSE), showing that routing was cosmetic. In Cortex-M, clean routing MSE is 0.000000 while scrambled routing MSE is 3.703950—yielding a causality ratio exceeding 10,000× (and >20,000× in M2M-100). The sparse routes are causally essential.

Combinatorial Wall Broken: By decomposing N=32 into 4 clusters of size 8 with macro-gist modulation, candidate route evaluations dropped from 496 down to 62 (an 87.5% reduction in search complexity). Coupled with synaptic memory priors, N=32 routing executes in 4.00 ms on CPU with zero divergence.

VI. Conclusion

Cortex-M demonstrates that connectionist memory, pre-verbal gist compression, and causal sparse routing can be unified without relational databases, regex heuristics, or large-scale compute infrastructure. The complete system executes on standard CPU hardware with negligible memory consumption, offering a principled biological alternative to decoupled von Neumann AI architectures.
