| Retrieved Cortex-M gist can condition MIMO routing | Demonstrated on a synthetic two-mode N=8 task; robustness partial | `GistConditionedM2M` adds an encoder whose output is added to the router context. The task mode was sampled independently of the numeric input; ten-seed matched run used the same data/training schedule for the archived no-gist baseline. True retrieved gist: 95.83% mean exact graph (9/10 seeds at 100%, seed 808 at 58.33%), mean MSE 0.01365. No gist: 0.017% exact graph, MSE 0.88455. Flipped gist: 0% exact graph, MSE 3.48393. Correcting stored mode alpha→beta changes the actual inference vector, route and output; missing/conflicted gist is rejected. Artifacts: `results/mimo-gist-conditioned/`; runtime/test: `src/cortex_m/integrated.py`, `tests_mimo/test_m2m_integration.py`, and `tests/test_visualizer.py`. The runtime schema still encodes only alpha/beta, and one seed failed, so the gain is bounded and not robust enough for default/general use. |

It shows architecture matters even when the context signal is informative. Saved under `results/mimo-gist-direct-route/`; it is not used by the visualizer. |
