## 🏛️ Standard Architecture Across All Specifications
1. **The Newborn Substrate Principle (Tabula Rasa)**: Systems ship devoid of hardcoded domain facts or canned question-answer shortcuts; all factual knowledge is acquired continuously on the go through interaction with the user.
2. **Deterministic Safety Separation**: Neural associative inference supervises and proposes; hardware safety interlocks, financial ledgers, and surgical/flight controls remain strictly deterministic.
3. **Purpose-Driven Visual Environments**: Complies with the 70/20/10 composition rule and purpose-tailored chromatic identities defined in [docs/architecture/design_system.md](../architecture/design_system.md).
