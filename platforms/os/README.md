## Overview
**CORTEX-OS** is a next-generation user-space cognitive operating environment. Rather than forcing users into rigid, static folder hierarchies, CORTEX-OS dynamically organizes files, research papers, source code, and applications by **semantic associative affinity clusters** while providing zero-latency spotlight memory search.

---

## Key Capabilities
- **Associative Omnibar Search**: Instant spotlight search finding documents by conceptual meaning rather than exact keywords.
- **Cognitive Affinity Clusters**: Dynamic groupings of active projects (e.g. *Robotics Simulation*, *Cortex-M Research*, *Personal Vault*) based on live working memory.
- **Zero-Footprint Runtime**: Dormant low-rank factor footprint ($<2.5\text{ MB}$) that wakes on demand without degrading OS responsiveness.
- **Userspace Sandboxing**: Operates as a userspace service on Linux, macOS, and Windows without replacing core OS microkernels.
