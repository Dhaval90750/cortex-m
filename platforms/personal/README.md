## Overview
**CORTEX-Personal** is an offline, privacy-first personal intelligence assistant for desktop and mobile devices. Backed by CORTEX-Synapse continuous attractor memory, it retains user preferences, project notes, and episodic facts in physical synaptic connection weights without transmitting data to external cloud servers or relying on third-party vector databases.

---

## Key Capabilities
- **Continuous Hopfield Recall**: Sub-millisecond associative recall ($<500\ \mu\text{s}$) over personal memories.
- **Epistemic Evidence Badges**: Visual indicator badges (`VERIFIED`, `PARTIALLY_SUPPORTED`, `INSUFFICIENT_EVIDENCE`) informing the user of confidence and grounding.
- **3D Energy Landscape View**: Visual display of the recurrent energy descent into stored attractor minima.
- **Tenant & Device Paging**: 2 KB low-rank factor isolation ensuring private personal memories never leak across profiles.
